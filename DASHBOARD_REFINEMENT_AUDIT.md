## 6. Gaps found against the brief

- The provenance legend is hidden inside the collapsed "Columns and characteristics" panel. It uses
  abbreviations, and neither the legend nor the cell badges have keyboard-accessible help.
- Stata descriptive figures are only in Methods → figure register, plus one download line in the explorer.
- Reader-facing labels are raw model IDs everywhere.
- Navigation: 11 flat buttons with `role="tab"` but no tab keyboard model and no tabpanel. These are
  route controls, so link semantics are the correct fix.
- Overview: "v38 core RoB and GRADE complete under delegation" sits beside a one-line outstanding list.
- No dashboard build SHA/date is shown in the page body; only the tiny fixed build badge has it.
- Downloads: 71 cards in one ungrouped grid.
- Theme toggle: no persistence, `aria-pressed` is set to the *previous* state, and dark/light is not
  announced. The contract forbids `localStorage.setItem` in `current_review_ui.js` (hidden-state guard), so
  persistence would need a separate, narrowly tested theme script.
- `fetch(` is forbidden in `current_review_ui.js`, so build metadata cannot be fetched there. `build_site.py`
  can embed it at build time instead.
- Contrast: amber `E2` matrix cells and badges use light text on `#d97706` in the light theme (≈3:1).
- Touch targets: `main` and `sens` matrix cells are 14 × 14 px buttons.
