# Additional file 12. Trial-by-trial accounting for the primary opioid outcome

**Why this file exists.** The review included 70 reports representing 69 trial families, yet the principal comparison for the registered primary outcome — all delivered systemic opioid, end of surgery to 24 hours, in mg IV MME — rests on a single trial. This file accounts for every included report against that outcome, so the reduction from 69 trial families to one principal contrast can be audited report by report.

## Method note

Tier A1 is reproduced from `10_FINAL_ADJUDICATION/06_REPORTS/primary_evidence_table.csv`; Tier A2 from `10_FINAL_ADJUDICATION/04_MODELS/model_inputs.csv`. Classifications, dispositions and source locators are reproduced as recorded; nothing was reclassified in producing this file.

Tier B grades were derived by automated search of each report's hash-pinned source text for opioid-outcome phrases, their co-location within 250 characters of a 24-hour window marker, and numeric data in the same context. **This is a screening signal to direct human attention.** It does not establish that an eligible result exists, nor that any report was wrongly handled. A B1 grade means only that a missing decision should be made and recorded.

No result was added, removed, reclassified or recomputed in producing this file.

**Accompanying data files:** `additional_file_12_A1_primary_construct.csv`, `additional_file_12_A2_other_windows.csv`, `additional_file_12_tierB_no_candidate_result.csv`.
